# Skills and evidence

**WORK IN PROGRESS.** The README maps foundational data-science skills to concrete evidence. Core skills include hypothesis design, Python/pandas/NumPy data wrangling, missingness analysis, visualization, financial feature engineering, statistical inference, temporal validation, regularized classification, boosting, calibration diagnostics, portfolio accounting and reproducible software.

`dataset.py` implements identity and feature contracts. `eda.py` implements grain-aware exploratory statistics and multiplicity control. `evaluation.py` implements train-only sector context and paired return tests. `modeling.py` implements matched rolling ablations. `candidate.py` provides private artifact preparation and batch scoring. Tests and GitHub Actions provide offline engineering checks; results/provenance.json preserves original-run evidence.

The development workflow applied SP500 data-science, ML-engineering, finance-review and deployment checklists. These are workflow practices, not professional certification or independent human review. This documentation captures learned practices without publishing personal agent configuration.

Reporting null findings, data corrections and failed exact-parity controls demonstrates critical interpretation. Hosted inference, automated alerts, registry operations and broker execution remain planned; they are not claimed as completed capabilities.
